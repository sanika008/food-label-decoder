# Food Label Decoder

AI-powered food label analysis system using OCR, fuzzy matching, and clustering.

## Features
- OCR extraction using Tesseract
- Harmful ingredient detection
- Fuzzy matching with RapidFuzz
- TF-IDF + K-Means clustering
- Streamlit interface

## Technologies
- Python
- Streamlit
- Pytesseract
- RapidFuzz
- Scikit-learn

## Run Locally

```bash
streamlit run datm.py
